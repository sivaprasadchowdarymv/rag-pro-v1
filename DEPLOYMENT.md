# Deployment (free): Streamlit Community Cloud + Hugging Face storage

About 30 minutes. No credit card is needed for any of the services below on their free plans.

| Service | What it does | Required? |
|---|---|---|
| Groq | Writes the answers (the AI) | Yes (or Ollama Cloud) |
| Ollama Cloud | Second AI provider, used as a fallback | Optional |
| Hugging Face | Keeps chats, feedback, preferences and document indexes across restarts | Strongly recommended |
| Streamlit Community Cloud | Runs the app at `https://<name>.streamlit.app` | Yes |

---

## Step 1: Groq key (3 min)

1. Open **console.groq.com** and sign in.
2. Go to **API Keys** → **Create API Key**.
3. Copy the key (it starts with `gsk_`) into Notepad.

## Step 2: Hugging Face token for storage (5 min)

1. Create an account at **huggingface.co/join** and verify your email.
2. Click your profile picture → **Settings** → **Access Tokens** → **Create new token**.
   * **Token type:** **Write**
   * **Name:** `rag-pro-storage`
3. Copy the token (it starts with `hf_`) into Notepad.
4. Choose a dataset name: `<your-hf-username>/rag-pro-data`.
   * You don't need to create it: the app creates it as a **private** dataset on first start.
   * You can also create it yourself at **huggingface.co/new-dataset** (set it to **Private**).

> The dataset holds text from your documents and your chats. Keep it private, and never share the token.

## Step 3 (optional): Ollama Cloud key

Go to **ollama.com/settings/keys** → **Add API Key** → copy it.

## Step 4: Push the code to GitHub (5 min)

In your project folder (PowerShell):

```powershell
git status          # must NOT list .env, secrets.toml, data/ or any .pdf
git add .
git commit -m "RAG∞ Pro: private workspaces, persistent storage, stronger verification, new UI"
git push
```

## Step 5: Deploy on Streamlit Community Cloud (10 min)

1. Open **share.streamlit.io**.
2. If an app already uses this repo, it redeploys automatically after the push. Go to its **⋮ → Settings → Secrets**.
3. Otherwise:
   * Click **Create app** → deploy from GitHub.
   * Repository: `<you>/gr_RAG`, branch `main`, main file `app.py`.
   * Open **Advanced settings** and choose **Python 3.12**.
4. Paste this into **Secrets**, using your real values, **inside double quotes**:

```toml
GROQ_API_KEY = "gsk_..."
HF_TOKEN = "hf_..."
HF_DATASET_REPO = "your-hf-username/rag-pro-data"

# optional
OLLAMA_API_KEY = "..."
APP_PASSWORD = "choose-a-password"
```

5. Click **Save**, then **Deploy** (or **Reboot app** if it was already deployed). Wait 3–6 minutes.

## Step 6: Check it works (5 min)

1. **Sidebar → Status** should show:
   * 🟢 **Groq: connected**
   * 🟢 **Storage: saved to Hugging Face** (if it says "temporary", check `HF_TOKEN` and `HF_DATASET_REPO`)
2. **Chat:** upload a PDF on the welcome screen. The first time, the app downloads its search models (~210 MB). Then click a suggested question.
3. Check the answer has a badge: **✓ Verified**, **≈ Partly verified** or **⚠ Check sources**. Open **Evidence** to see the exact excerpts.
4. **Settings → Workspace & storage:**
   * Copy your **workspace link** and bookmark it.
   * Click **Save now**. "Pending changes" should drop to 0.
5. **Test persistence:** on share.streamlit.io, click **⋮ → Reboot app**, then open your bookmarked link. Your chats and documents come back without uploading again.
6. **Validate:**
   * Pick your document → **Generate test questions** → review them.
   * Click **Check retrieval** (free).
   * Then click **Full test** (uses your AI quota). You get retrieval hit rate, answer accuracy, correct-page citations and the verified rate on your own datasheet.

## Updating later

```powershell
git add . ; git commit -m "describe change" ; git push
```

Streamlit redeploys automatically. Your data stays in the Hugging Face dataset.

## How privacy works

* Every visitor gets a **private workspace**. Its key is a 24-character random code in the link (`?ws=…`). Without the link, nobody can see that workspace's chats, feedback, preferences or document list.
* **Anyone who has your link can open your workspace**, so treat it like a password. Set `APP_PASSWORD` to lock the whole app.
* Document indexes are stored by content hash, so identical PDFs are indexed once. A document only appears in workspaces where it was uploaded.
* Answers are generated by Groq or Ollama Cloud, so excerpts of your documents are sent to them.

## Limits

* **Upload batching:** changes are uploaded every ~45 s (or with "Save now"). A crash can lose the last few seconds.
* **Sleep:** the app sleeps after ~12 h without visitors; the next visitor wakes it.
* **Rate limits:** free AI tiers have per-minute limits. Use **Settings → AI models → Quick** to save quota, or add a second provider.
* **Hugging Face storage:** a free account has storage limits for private repositories. Typical use (chats + indexes of datasheets) is small. Check huggingface.co/pricing if you index thousands of documents.

## Self-hosting instead

Run `streamlit run app.py` on any server. For persistent storage on that server's own disk, set:

```
HF_DATASET_REPO=file:///absolute/path/to/backup-folder
```
